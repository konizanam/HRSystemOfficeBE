# Assumptions

This file lists every **ASSUMPTION** from `BUILD_SPEC.md`, plus the decisions taken during the build where the spec was silent. The open points in spec section 18 still need confirmation from the business.

Coverage: `grep -n ASSUMPTION BUILD_SPEC.md` finds 18 assumptions in the body of the spec (sections 4.1, 4.2, 4.3, 5.1, 5.2.1, 5.2.2, 5.2.4, 5.3.1 twice, 5.4.1 twice, 5.4.2 twice, 5.4.3, 5.4.4 twice, 5.4.6 and 14). They are A1 to A18, in that order. The other hits are instructions about this file (the preamble and sections 17 and 18). Rows from A19 on record readings the spec left open, and the B rows record build decisions.
